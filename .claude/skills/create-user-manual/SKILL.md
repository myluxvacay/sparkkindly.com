# Skill: Create User Manual

Use `.claude/templates/user-manual.md`. Visitor-facing help lives on the site; owner/admin manuals under `docs/manual/`.

Include:
overview
audience
prerequisites
permissions (age group, role)
navigation
step-by-step tasks
field descriptions
examples
screenshots/placeholders as appropriate
errors/troubleshooting
FAQ
related features
version/date

Plain language; no jargon for visitor-facing text.
